Do you ever consider that you are a machine? So one of the things I do aside from make animations is work on tools for making art with code. This is an attempt at making something with those tools. All the visuals are coded up using p5.js, an open-source graphics library I help maintain, within butter.video (my day job!), a browser-based motion graphics editor where you can write and edit graphics code in a timeline. For a long time I've wanted something like Flash to exist again where you can pop open the Actions panel and write some code, and also continue to edit on the timeline, and that's basically what Butter can do now for p5.js code! Since this is primarily useful for motion graphics rather than character animation, I made something that can be mostly motion graphics. Is the spoken word cringe? Maybe a bit! But we could all use to be a bit more cringe sometimes.
